Today we're going to learn how to make grids using CSS.
Just follow these points:

-:Steps to make grids,tables and rows:-

(I)
We create a container first with class(.container) then assign it to div class.For neatness,we create grid gaps,which creates the spaces between columns and rows.

(II)
Then we create the classes for sections too,if we want,we can make their borders too,

(III)
The command (grid-template-columns) creates the columns and decides their widths,like auto auto auto; ot 200px 50px 100px; .

(IV)
The command (grid-template-rows) decides how tall the columns/cells are in a particular row,e.g. auto auto auto; or 200px(first cell) 50px(second cell) and so on.

(V)
To create more elegancy,once you write a text in section tag,you can create paddings too,i'd recommend padding around 50px.

(VI)
This is an important concern.Imagine you want to create 9 cells each 3 starting on new row.How CSS automatically knows when to use second row?
We know we wrote 200px 50px 100px; earlier,when the columns with these heights and widths fill up the first row of container,they automatically switrch to the other one to fill it.Until all your demanded columns are created.
